Demos

Each demo under tests/Demos runs to the end, one after another, in one process.

10 demos in 10 files. Run: cd Typescript && npm run test:demos:run-all. Source: Typescript/tests/

Affinity_Model.tsran

Project scoreboard: derived scores, filtered reads, a reactive score update.

City_Scale.tsran

City Scale benchmark; prints its own PASS and timings.

Concurrent_Storm.tsran

1,000 sequential blackouts across 100k districts, no locks.

Hemisphere_1M.tsran

One sensor change reaches the hemisphere through 6 nodes.

Robots_Contexts.tsran

Robots data read in different contexts.

Root_Fanout_100k.tsran

Root fan-out benchmark: one root write reaching many dependents.

ShopsExample.tsran

Coffee Shops demo.

Smart_City.tsran

Smart City demo.

Social_Graph.tsran

Social Graph demo.

WalletSplit.tsran

Shared wallet for a Vancouver trip: expenses split between identities.

run-all.ts runs each demo in turn and prints PASS: all .me demos at the end. A demo that throws stops the run. Some demos print their own PASS line and timings; the check here is that each one completes.
