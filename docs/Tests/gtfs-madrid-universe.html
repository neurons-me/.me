What this is

A tiny GTFS-Madrid-shaped knowledge universe runs live on the this.me kernel. Click any node to select it and call me.explain(path) — dependsOn highlights in cyan; after a mutation the recomputed wave is red. Selected node keeps a gold ring.

Honesty, matching the blog and the benchmark README: this is not an RML/RDF materialization run. CREATE is measured via explicit gtfs.idx membership slots (flip 0→1), not as “natural GTFS CREATE k=1”. Loading a larger snapshot costs more; that is not the same as recomputation after a mutation. Density adds ghost points for visual scale only — they are not wired into the kernel.

Kernel: published this.me@4.1.0 (hash-pinned). Isolation demos still pin 4.0.2; DELETE via me["-"] needs 4.1.0 for ABSENCE invalidation. Append ?local=1 to load ../../Typescript/dist/me.es.js instead (static serve from repo root).
